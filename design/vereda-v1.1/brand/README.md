# Vereda Expeditions · brand files · the live logo (option C "the name, set once", chosen 11 Oct 2026)

The logo is the name: "vereda." set once in Fraunces variable (weight 700, optical size 144, SOFT 100, WONK 1) and outlined to paths; the v terracotta #A83E24, the five letters ink #1F1B17, the full stop ochre #F2B134. Ascender of the d = 32 units = the box height; x-height 18.9; the font's own spacing. Never retyped, never a capital V, never without the stop. The monogram "v." (x-height 20 in the 32 box) goes only where a word cannot: favicon, app tile, push badge, QR centre, 40 px avatar. "EXPEDITIONS" is Inter 600, tracked 0.2 em, teal #0B4F6C, right-aligned under the a (full lockup) or centred (stacked). On dark teal: ochre v and stop, white letters. Fonts SIL OFL; the outlines are free to use. Generated by `tools/brand_bc.py` (also writes `option-c/`, which is identical to this folder's logo files).
