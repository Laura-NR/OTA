What the build needs that the canvas does not contain

Every artboard draws its logo, icons and photos inline or as tinted placeholders so the design reviews honestly. This sheet lists the real files behind them: format, who produces them, and what the build does until they exist. Legend: on canvas, usable placeholder on canvas needed third party.

01 · Logo and brand files designed · B-Logo · files in design-canvas/brand/

mono

The logo on every artboard is the wordmark of B-Logo: "vereda." set once in Fraunces 700 (optical size 144, SOFT 100, WONK 1) and outlined, the v terracotta, the full stop ochre; chosen on 11 Oct 2026 over the trail-and-sun mark and the fanlight (B-Compare). The build ships the files, never retypes the name: vereda-wordmark.svg (header, light), -white (dark teal), -mono; vereda-logo-full.svg for print; vereda-mark.svg (the monogram "v.") for favicon, app tiles, push badges and the QR centre. Header height 28 px web, 26 px admin and mobile; nothing beside the wordmark.

02 · Typefaces on canvas, usable

Frauncesdisplay · variable opsz 9–144, wght 300–700 · SIL OFL 1.1
Interbody and UI · 400–700 · SIL OFL 1.1
IBM Plex Monocodes, money, timers · 400, 500 · SIL OFL 1.1
  • Production: self-hosted WOFF2, subset Latin + Latin Extended (ñ, ç, é, ü, ¿ ¡), font-display: swap, preload Inter 400 and Fraunces 600; the canvas loads Google Fonts for the prototype only.
  • Budget: Inter variable ≈ 95 KB, Fraunces variable ≈ 120 KB, Plex Mono 2 weights ≈ 50 KB. Low-bandwidth mode (DS 05) loads system fallbacks: Georgia, system-ui, ui-monospace.
  • Emails: system stacks only (DS 06), never web fonts.
  • PDFs: embed Fraunces and Inter in the generator (OFL permits embedding); mono for codes and totals.
  • Worker app: Inter bundled; Fraunces only on the sign-in screen.

04 · The Cuba map file supplied 11 Oct 2026

The map on Map-Concept, Destinations and M-Destinations is the Simplemaps Cuba file Vereda supplied: one path per province keyed by the ISO 3166-2:CU number, plus a label point per province. The build keeps the file and adds the data file the shell fills with live coverage (spec §3.2).

  • Source and licence: Simplemaps.com (© 2024 Pareto Software LLC), free for commercial use under the Simplemaps SVG licence; attribution is requested, so every rendering keeps the small "Map: Simplemaps.com" credit in its corner. No Google or Mapbox tiles anywhere: one SVG, cached, works offline (DS 05).
  • States: active teal-100 fill, teal-600 stroke; limited accent-100 fill; not_yet neutral-100 fill, 45° hatch (not colour alone); hover / focus 2 px teal ring; selected teal-600 fill, white label.
  • Semantics: each province is a <a href="/destinations?province=CU01"> wrapping the path with an aria-label "Pinar del Río, active network, 9 casas, 6 tours"; the strip and list under the map are the same links, so the map is never the only way.
  • Labels: a separate text layer at the centroids, hidden under 600 px wide; markers for the 14 destinations as a second layer.
  • Owner: Vereda supplied the file (kept in the repository beside the canvas tools); build adds provinces.json and destinations.json; design owns the styling tokens on Map-Concept.
