# Brand files (default tenant)

The live logo, option C "the name, set once", copied unchanged from
`design/vereda-v1.1/brand/` (identical in `design/vereda-v1.2/brand/`); that
README holds the usage rules. In short: the wordmark is 28 px high on web and
26 px on admin and mobile, with nothing beside it. The monogram "v." is used
only where a word cannot go (favicon, app tile, push badge, QR centre). Never
retype the wordmark.

The apps import these files at build time (`src/lib/brand.ts`). The raster
exports (favicon PNGs 32 / 180 / 192 / 512, app icons, `og-default.jpg`, the
email logo) are still to come from Vereda (T-Signoff §03).
